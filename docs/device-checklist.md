# iPhone 17 Pro / LiveContainer 実機確認

各項目の合格判定は改造版ごとに行う。ブラウザの契約テスト成功は実機再生の成功を意味しない。

最新の利用者確認（2026-11-27）: 0.2.3/build 8提供後、「自動PiPは必要ではなく、現状は理想どおりの動作」との報告を受けた。現在の挙動を維持し、自動PiPは対応対象から外す。以下の個別チェック項目は、具体的な確認報告に応じて更新する。

0.2.0/build 4の利用者報告: PiPを維持したままアプリを背景から復帰すると停止し、再生ボタンで再開できる。ライブPiPは開始するが途切れる。全画面の右側パネル切替が開かない（上下ボタンは動作）。0.2.1ではパネルを隠すCSSを撤去し、PiP/背景移行時の全画面解除・回転と復帰時イベント再送を撤去した。PiP症状の原因確定・実機改善確認はまだできていない。

0.2.1/build 5の利用者報告: コントロールセンター開閉・背景復帰で録画/ライブとも停止。PiP単独の復帰ではなく、背景へ移る操作に伴う。ライブは停止後不安定。LiveContainer 3.8.14、自動PiP設定ON。0.2.2の診断記録でイベント順を確認する（diagnostics.md参照）。

0.2.2/build 7の提供ログ（iOS 26.7.3）では、PiP背景復帰5回すべてで音声セッション再有効化の最中～直後にpauseを観測。0.2.3は復帰時の再設定だけを撤去した。実機改善・Control Center全症状の因果・自動PiPは未確定。

新しい`KonomiTV FS`を別アプリとして導入し、元アプリのデータ領域を削除・共有しない。同じ改造版を更新するときはLiveContainer内で同じアプリ/データ領域を選ぶ。今回のIPA SHA・版・build番号を記録してから確認する。

失敗時は操作順、再生種別、画質、端末/LiveContainer/iOS版、結果画像を記録する。認証情報・Cookie・録画の私的情報は共有しない。実機確認が終わるまで追加機能へ進めない。

## 0.3.0の背景音声（未確認）

通常表示と全画面、HEVC録画とライブを分けて確認する。安定版0.2.3のIPAを残しておく。

- [ ] PiPを出さずHomeへ戻る／画面をロックする。音声が継続し、5分以上でも途切れない
- [ ] 背景から復帰して元の動画と操作部品が使える。ライブが不安定にならず、録画の位置が維持される
- [ ] 停止してから背景へ移っても再開しない。背景で音声継続後、ロック画面／Control Centerの停止が維持される
- [ ] 背景入り直後の停止ボタンが勝手に解除されない。Control Centerの開閉だけでは再生状態を変えない
- [ ] 手動PiPの開始・背景移行・復帰が従来どおり動作する
- [ ] 電話・Siri・別アプリの音声開始を妨げない。終了後も利用者が再生操作できる
- [ ] 画質／番組／チャンネル切替、認証画面への遷移で旧動画が再開されない

音声が続かない場合は診断JSONを保存する。startedイベントがあっても音声継続の成功扱いにはせず、実際に聞こえた期間と操作順を記録する。
